## Warum es dieses Tool gibt

XP-Inseln können umbenannt, deaktiviert oder gepatcht werden, während alte Codes weiterhin im Umlauf sind. Das Statusboard platziert den letzten Haken neben jedem Code und ermöglicht es den Spielern, die Liste nach AFK-Flow oder Timer-Verhalten einzugrenzen, bevor sie Creative starten.

## Was das Tool macht

### 01 · Inselcode-Statustafel

Trennt erreichbare Codes von deaktivierten oder gepatchten Einträgen.

### 02 · No-Timer- und AFK-Filter

Filtert Inseln nach Timer-Stil, AFK-Flow und letzter Überprüfungszeit.

### 03 · zuletzt überprüfte Zeitstempel

Kopiert einen Code mit einem Klick und speichert nützliche Einträge in einer Favoritenliste.

## Die Oberfläche

- **01.** Die Statustafel ist in aktive, unsichere und gepatchte Inseln aufgeteilt.
- **02.** No-Timer- und AFK-Filter für den gewünschten Kartenfluss.
- **03.** Codekarten mit Ersteller, letzter Kontrolle und Schnellkopie-Aktion.
- **04.** Favoriten für Codes, die es wert sind, nach einem Update erneut getestet zu werden.
- **05.** Kompakter Prüfverlauf für geänderte oder deaktivierte Inseln.

## Auf einen Blick

| Funktion | Ergebnis |
|---|---|
| **Eingabe** | Kartentyp + Statusfilter |
| **Ergebnis** | Aktueller Inselcode |
| **Ausgabe** | Favoriten und kopierte Codes |

## Geeignet für

- Finden Sie aktive Kartencodes
- Filtern Sie No-Timer- oder AFK-Karten
- Vermeiden Sie gepflasterte Inseln

## Ergebnisse richtig lesen

Status und Zeitpunkt der letzten Überprüfung sollten zusammen gelesen werden. Aktiv bedeutet, dass der Code während der aufgezeichneten Prüfung funktioniert hat, während unsicher bedeutet, dass die Insel erneut besucht werden muss. Filter beschreiben den gemeldeten Fluss der Karte; Sie garantieren keine feste XP-Rate, da sich Inseln und Belohnungen ändern können.

## Vor dem Start

- **Kartentyp + Statusfilter** bereithalten und prüfen, ob die Daten zum vorgesehenen Fortnite Creative-Profil bzw. zur Sitzung gehören.
- Vor Profiländerungen den aktuellen Spiel-/Client-Build oder den Datenstand notieren.
- Speicherort für **Favoriten und kopierte Codes** festlegen, damit das vorige Ergebnis nicht überschrieben wird.
- **Inselcode-Statustafel** zuerst in einem kurzen Test verwenden und Original-Save, Profil oder Vergleich daneben behalten.

## Daten und Wiederherstellung

Codes und Statusverlauf sind lokale Referenzdaten. Das Etikett „Zuletzt geprüft“ ist ein Beweis für eine frühere Prüfung und kein Versprechen, dass eine Insel weiterhin verfügbar ist.

<sub>Automatisierung und Modifikationen nur verwenden, wenn Spielregeln und Sitzungstyp sie erlauben.</sub>

## Der erste vollständige Durchlauf

1. **Fortnite XP-Map-Codes** öffnen und den erkannten Fortnite Creative-Build bzw. die Datenquelle prüfen.
2. Eingabe oder Profil wählen und **Inselcode-Statustafel** konfigurieren, ohne unbeteiligte Standardwerte zu ändern.
3. **No-Timer- und AFK-Filter** in Vorschau oder Statusanzeige prüfen und Versions-, Filter- oder Erkennungswarnungen beheben.
4. Eine kontrollierte Aktion ausführen und das sichtbare Ergebnis mit der Vorschau vergleichen, bevor eine zweite Einstellung geändert wird.
5. Profil speichern oder Ergebnis exportieren; **zuletzt überprüfte Zeitstempel** für Vergleich und Wiederherstellung behalten.

## Nach einem Spiel-Update

- [ ] Sortieren Sie nach der zuletzt überprüften Option und verschieben Sie alte Favoriten zurück in den unsicheren Status.
- [ ] Öffnen Sie die Codes einzeln, da sich eine Insel ändern kann, ohne ihren Code zu ändern.
- [ ] Überprüfen Sie die Timer- und AFK-Beschriftungen erneut anhand des aktuellen Inselflusses.
- [ ] Behalten Sie deaktivierte Einträge im Verlauf bei, damit recycelte oder irreführende Codes erkennbar bleiben.

## Fehlerbehebung

> **Häufiges Fehlerbild:** Ein XP-Kartencode ist deaktiviert oder gepatcht.

### Ein Code öffnet eine andere Insel

Vergleichen Sie die Angaben zum Ersteller und zur letzten Überprüfung. Eine wiederverwendete Auflistung kann auf eine geänderte Insel verweisen.

### Ein aktiver Code funktioniert nicht mehr

Versetzen Sie es in den unsicheren Status und behalten Sie die Prüfzeit bei; Die Verfügbarkeit der Insel kann sich ohne Vorankündigung ändern.

### Die Liste fühlt sich altbacken an

Sortieren Sie nach zuletzt überprüften Favoriten und testen Sie gespeicherte Favoriten erneut, bevor Sie ältere Einträge durchsuchen.
