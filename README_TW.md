## 為什麼需要這個工具

XP 島可以重新命名、停用或修補，而舊程式碼則繼續流通。狀態板將最後一個檢查放在每個程式碼旁邊，讓玩家在啟動創意之前透過 AFK 流程或計時器行為縮小清單範圍。

## 主要功能

### 01 · 島嶼代碼狀態板

將可到達的程式碼與停用或修補的條目分開。

### 02 · 無定時器和 AFK 過濾器

按計時器樣式、AFK 流程和上次驗證時間過濾島嶼。

### 03 · 最後檢查的時間戳

一鍵複製程式碼並將有用的條目保留在收藏夾清單中。

## 介面說明

- **01.** 狀態板分為活躍島、不確定島、修補島。
- **02.** 無計時器和 AFK 濾鏡可滿足所需的地圖流程。
- **03.** 帶有創建者、最後檢查和快速複製操作的代碼卡。
- **04.** 更新後值得重新測試的程式碼的收藏夾。
- **05.** 壓縮檢查已更改或停用島嶼的歷史記錄。

- 過濾無計時器或 AFK 地圖
- 避免修補島嶼

## 如何理解結果

狀態和上次檢查時間應一起讀取。活躍意味著代碼在記錄的檢查期間有效，而不確定意味著該島需要再次訪問。過濾器描述了地圖的報告流程；他們不保證固定的 XP 比率，因為島嶼和獎勵可能會改變。

## 開始之前

- 準備好 **地圖類型+狀態過濾器**，並確認它屬於目標 Fortnite Creative 設定或連線。
- 變更設定之前，記錄目前遊戲/用戶端版本或資料日期。
- 先選擇 **收藏夾和複製的程式碼** 的儲存位置，避免覆蓋上一次結果。
- 先用 **島嶼代碼狀態板** 進行一次短測試，並保留原始存檔、設定或比較記錄。

## 資料與還原

程式碼和狀態歷史記錄是本地參考資料。最後檢查的標籤是過去檢查的證據，而不是島嶼仍然可用的承諾。

<sub>自動化與修改功能僅限遊戲規則和目前連線類型允許時使用。</sub>

## 完成第一次使用

1. 開啟 **Fortnite 經驗地圖代碼**，確認偵測到的 Fortnite Creative 版本或資料來源。
2. 選擇輸入或設定，只調整 **島嶼代碼狀態板**，先保留與本次測試無關的預設值。
3. 在預覽或狀態面板檢查 **無定時器和 AFK 過濾器**，處理版本、篩選或辨識警告。
4. 只執行一次可控制的操作。在修改第二項設定之前，將實際結果與預覽比較。
5. 儲存設定或匯出結果，並保留 **最後檢查的時間戳** 以便比對或還原。

## 遊戲更新之後

- [ ] 按上次檢查排序並將舊的收藏夾移回不確定狀態。
- [ ] 單獨打開代碼，因為島嶼可以在不更改其代碼的情況下發生變化。
- [ ] 根據目前島嶼流程重新檢查計時器和 AFK 標籤。
- [ ] 將已停用的條目保留在歷史記錄中，以便重複使用或誤導性代碼仍然可以識別。

## 問題排查

> **常見問題:** XP 地圖程式碼已停用或已修補.

### 一個密碼打開不同的島嶼

比較創建者和最後檢查的詳細資訊；重複使用的清單可能指向已更改的島嶼。

### 活動代碼不再有效

將其移至不確定狀態並保持檢查時間；島嶼的可用性可能會發生變化，恕不另行通知。

### 該列表感覺陳舊

在瀏覽舊條目之前，請按上次檢查的順序排序並重新測試已儲存的收藏夾。
