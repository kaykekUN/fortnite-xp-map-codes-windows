## 이 도구가 필요한 이유

이전 코드가 계속 유통되는 동안 XP 섬의 이름을 바꾸거나 비활성화하거나 패치할 수 있습니다. 상태 보드는 모든 코드 옆에 마지막 확인 사항을 표시하고 플레이어가 Creative를 실행하기 전에 AFK 흐름이나 타이머 동작을 기준으로 목록 범위를 좁힐 수 있도록 해줍니다.

## 주요 기능

### 01 · 섬 코드 상태 게시판

연결 가능한 코드를 비활성화되거나 패치된 항목과 분리합니다.

### 02 · 타이머 없음 및 AFK 필터

타이머 스타일, AFK 흐름 및 마지막 확인 시간을 기준으로 섬을 필터링합니다.

### 03 · 마지막으로 확인한 타임스탬프

한 번의 클릭으로 코드를 복사하고 즐겨찾기 목록에 유용한 항목을 유지합니다.

## 화면 구성

- **01.** 상태 보드는 활성화된 섬, 불확실한 섬, 패치된 섬으로 나뉩니다.
- **02.** 원하는 지도 흐름을 위한 타이머 없음 및 AFK 필터.
- **03.** 작성자가 있는 코드 카드, 최종 확인 및 빠른 복사 작업.
- **04.** 업데이트 후 다시 테스트할 가치가 있는 코드를 즐겨찾기에 추가합니다.
- **05.** 변경되거나 비활성화된 섬에 대한 간략한 확인 기록입니다.

## 이럴 때 유용합니다

- 활성 지도 코드 찾기
- 타이머 없음 또는 AFK 맵 필터링
- 패치된 섬을 피하세요

## 결과 읽는 방법

상태와 최종 확인 시간을 함께 읽어야 합니다. 활성은 기록된 확인 중에 코드가 작동했음을 의미하고, 불확실함은 섬을 다시 방문해야 함을 의미합니다. 필터는 보고된 지도의 흐름을 설명합니다. 섬과 보상은 변경될 수 있으므로 고정된 XP 비율을 보장하지 않습니다.

## 시작 전 준비

- **지도 유형 + 상태 필터**을 준비하고 대상 Fortnite Creative 프로필 또는 세션의 데이터인지 확인합니다.
- 프로필을 변경하기 전에 현재 게임/클라이언트 빌드 또는 데이터 날짜를 기록합니다.
- 이전 결과를 덮어쓰지 않도록 **즐겨찾기 및 복사된 코드**의 저장 위치를 정합니다.
- 먼저 **섬 코드 상태 게시판**을 짧게 시험하고 원본 세이브, 프로필 또는 비교 기록을 보관하세요.

## 데이터 및 복구

코드 및 상태 기록은 로컬 참조 데이터입니다. 마지막으로 확인한 라벨은 과거 확인의 증거이지 섬이 계속 사용 가능하다는 약속이 아닙니다.

<sub>자동화와 변경 기능은 게임 규칙과 세션 유형이 허용하는 경우에만 사용하세요.</sub>

## 첫 실행 전체 과정

1. **포트나이트 XP 맵 코드**을 열고 감지된 Fortnite Creative 빌드 또는 데이터 원본을 확인합니다.
2. 입력이나 프로필을 선택하고 이번 테스트와 관계없는 기본값은 유지한 채 **섬 코드 상태 게시판**을 설정합니다.
3. 미리보기나 상태 패널에서 **타이머 없음 및 AFK 필터**을 확인하고 버전, 필터 또는 감지 경고를 해결합니다.
4. 제어 가능한 작업 하나만 실행합니다. 두 번째 설정을 바꾸기 전에 실제 결과를 미리보기와 비교하세요.
5. 프로필이나 결과를 저장하고 비교 또는 복구에 사용할 **마지막으로 확인한 타임스탬프**을 남겨 둡니다.

## 게임 업데이트 후 확인

- [ ] 마지막으로 확인한 항목을 기준으로 정렬하고 오래된 즐겨찾기를 다시 불확실한 상태로 되돌립니다.
- [ ] 코드를 변경하지 않고도 섬이 바뀔 수 있으므로 코드를 개별적으로 엽니다.
- [ ] 현재 아일랜드 흐름에 대해 타이머 및 AFK 라벨을 다시 확인하세요.
- [ ] 재활용되거나 오해의 소지가 있는 코드를 인식할 수 있도록 비활성화된 항목을 기록에 보관하십시오.

## 문제 해결

> **자주 발생하는 문제:** XP 맵 코드가 비활성화되었거나 패치되었습니다..

### 코드를 입력하면 다른 섬이 열립니다

작성자와 최종 확인 세부정보를 비교하세요. 재사용된 목록은 변경된 섬을 가리킬 수 있습니다.

### 활성 코드가 더 이상 작동하지 않습니다.

불확실한 상태로 이동시키고 점검 시간을 유지하십시오. 섬 이용 가능 여부는 예고 없이 변경될 수 있습니다.

### 목록이 오래된 것 같아요

이전 항목을 찾아보기 전에 마지막으로 확인한 항목을 기준으로 정렬하고 저장된 즐겨찾기를 다시 테스트하세요.
